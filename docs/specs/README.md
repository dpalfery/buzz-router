# Specifications

Upfront specification work for a greenfield project or a large feature, written when
requirements and architecture still need defining before a plan can exist.

Each specification gets a folder `docs/specs/<feature>/` containing `requirements.md`, `design.md` and `tasks.md`, plus any input brief. Read this index before opening a specification. Delivered specifications are archived to `docs/archive/specs/` after closeout and are never current guidance.
